# Перенос макета в игру — что сделано и что нет

Макет — `visual/kern-ui`. Переносим только ПК (клавиатура и мышь); тач и геймпад — позже.
В игру идёт только то, что есть в макете; то, что должен присылать сервер, в клиент не зашивается.

## Сделано

### Сцены и общее
- [x] Три сцены: Bootstrap → MainMenu → MainGame (вход и онбординг — слой поверх меню).
- [x] Токены, шрифты (Exo 2, Onest, JetBrains Mono), общие листы: клавиши, панели, поля, переключатели, ползунок с Т-ручкой и рисками.
- [x] Значки печатаются из спрайта макета (`visual/kern-ui/tools/emit-hud-icons.py`); «›››» на главной клавише — значок `i-arrows`.

### Вне игры
- [x] Экран загрузки клиента.
- [x] Вход и онбординг: язык, масштаб, размер текста, дальтоники, качество, FPS, VSync, HDR, калибровка, громкость, звук в фоне.
- [x] Главное меню: заголовок, «Играть», «Настройки», связь и выход справа, строка сборки.
- [x] Спуск: пояснение фазы, шкала ступенями, список фаз, отказ словами макета и «Повторить».
- [x] Совет на спуске — присылает сервер (`LoadingTipPacket`, код 49): один совет, клиент показывает последний присланный.
- [x] Убраны: окно «Проверка ресурсов», мёртвые окна меню, сценка меню (звёзды, станция).

### В игре
- [x] HUD: игрок, HP, деньги и кредиты, груз, кристаллы, геология, состояния, автокопание, программатор (кнопка), миникарта, системные кнопки, строка состояния с догрузкой, хотбар и раскрытый инвентарь, мини-навыки.
- [x] Пауза.
- [x] Окно настроек (общее с меню): Графика, Звук, Интерфейс, Управление.
- [x] Калибровка дисплея: HDR — пик, чёрный, белая точка; SDR — яркость.
- [x] Подтверждение ссылки (OpenURL).
- [x] Связь: потеря соединения, отключение сервером.
- [x] Подписи над роботами, облака локального чата, счётчик добычи у кристалла.
- [x] Карта мира: координаты под курсором, масштаб «×N», зум, «к себе», «Моя метка» (флажок + метка).
- [x] Чат: колонка, свёрнутые три строки, список каналов, счётчики непрочитанного; имя канала — из списка сервера; время — из пакета, моно.
