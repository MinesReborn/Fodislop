Путь: LightingFrameExecutor.Record → IndirectLightingSolver.RecordComposite → Assets/Resources/Shaders/Lighting/Composite/CompositeLighting.hlsl:CompositeLighting. Дефект 2 при явном refresh увеличивает обработку с partial до полного поля — это требуемая корректность, не ускорение. Обычные динамические кадры сохраняют partial-путь.
