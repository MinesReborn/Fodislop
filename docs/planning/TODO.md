- [ ] **6. Подтвердить server-driven конфигурацию клеток end-to-end**
  - В текущей сетевой схеме `CellConfigurationPacket` содержит только значения фиксированного размера: `Properties`, `DrawLayer`, `Outline`, `ReliefGroup`, `AnimationType`, `AnimationPalette`, `FrameAnimationSpeed`, `MapColor` и `TextureAnchor` — строк в нём нет, сериализация сводится к memcopy. Имя основной текстуры выводится из типа клетки по таблице `cells.json`, а декали приходят отдельной картой `WorldInitPacket.DecalMap` (одна общая текстура → набор клеток). Клиент передаёт эти описания из `WorldInitPacket` в `BlockRegistry.Prepare` и `MapCellConfigCatalog.LoadConfigurations`; визуальные поля применяются при сборке таблицы блоков. Группы тайлов и манифест ресурсов приходят отдельными полями `WorldInitPacket`.
  - `cells.json` загружается как начальная таблица `BlockRegistry`; при замене описаний из `CellConfigurationPacket` клиент сохраняет из прежней записи `MovementCooldownMs`, `TextureName` и имя `TileGroup`, а `DecalTextureName` берёт из `CellDecalMap`. Игровой cooldown приходит отдельно через `MovementSpeedPacket`, а ID групп тайлов строятся из `WorldInitPacket.TileGroups`.
  - `MapColor` остаётся незавершённой частью: поле уже есть в `CellConfigurationPacket`, но `MapCellConfigCatalog.GetCellMinimapColor32` сначала возвращает цвет из статической `MapBlockColors` для типов, отмеченных авторскими, и только затем читает packet. `MapBlockColors` строит палитру один раз из `BlockRegistry.Blocks` при первом обращении; сам реестр изначально читает `cells.json`, но `BlockRegistry.Commit` может заменить его до инициализации палитры. Поэтому источник значений палитры зависит от порядка первого обращения и серверного обновления, а не гарантированно от локального JSON. Комментарии клиента называют серверное значение заглушкой; фактическое построение пакета на настоящем сервере и порядок первого обращения в production не подтверждены этим checkout.
  - Следующий шаг — сверить построение `CellConfigurationPacket`, `MovementSpeedPacket`, `TileGroups` и `AssetsManifest` в репозитории сервера и завершить переход мини-/большой карты на серверные `MapColor`. Не добавлять поля, уже существующие в текущем контракте.
