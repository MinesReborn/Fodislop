Android // установка APK

Установка без магазина

Открыть на телефоне

  1. Открой эту страницу на телефоне — по QR-коду или ссылкой — и нажми Скачать APK.
  2. Открой скачанный файл. Если телефон спросит, разреши установку из этого источника: Настройки → Приложения → Специальный доступ → Установка неизвестных приложений, выбери браузер и включи Разрешить.
  3. Нажми Установить. Обновления приходят так же: новый APK ставится поверх, прогресс сохраняется на сервере.
  4. Игра идёт в альбомной ориентации — поверни телефон.

Проверка файла // sha-256

Файл тот, что мы выложили

Сравни контрольную сумму скачанного файла с суммой в списке выше. Не совпадает — файл повреждён или подменён, не запускай его и скачай заново с этой страницы.

Windows

certutil -hashfile файл SHA256

macOS

shasum -a 256 файл

Linux

sha256sum файл
