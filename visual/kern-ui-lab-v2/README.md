# Kern Interface Lab v2

Новый вариант полного интерактивного макета. Основа — `visual/kern-ui-lab`
целиком (все экраны, окна, дев-панель, i18n, звук, детектор переполнения);
оригинал не изменён. Перестроен игровой интерфейс по реальным клиентам:
раскладка Unity Legacy OpenMines, форматы Legacy/Kern, тексты сервера
(источники — `../kern-ui-rebuild/inventory.md`).

Открыть: `cd ~/Projects/games && python3 -m http.server 8765`, затем
http://127.0.0.1:8765/Fodislop/visual/kern-ui-lab-v2/index.html

## Что нового в игре (экран «5. ИГРА / HUD»)

- Панель игрока: полоса HP (клик — урон/лечение), клан, ник, `ур.N`, `NHP`,
  `$N`, кредиты; «Бонусы»; миссия — когда есть.
- «Груз N%» с порогами цвета и полосой перегруза, шесть кристаллов
  (растут при копании), бокс.
- Автокопание (E), программатор: открыть / ▶■, миникарта `x:y`.
- Чат Legacy: три строки → колонка (Enter / кнопка) → скрыт; каналы FED и
  Дно, список чатов, отправка сообщения.
- Справа: `ОНЛАЙН N (N)`, строка версии/FPS, помощь, консоль, здания,
  респаун (окно), полный экран, настройки, музыка, звук; инвентарь 4×55,
  ‹ раскрывает, TAB — окно инвентаря, 1–9 — слоты.
- Мини-навыки: появляются при росте навыка на 5 с; готовый — остаётся с
  «up», клик открывает окно навыков (здание UP) — выбор слота, описание
  сервера, «Улучшить», установка в пустой слот (18 навыков), покупка слота.
- Меню: при обязательном обновлении кнопка спуска заменена «ОБНОВИТЬ»;
  планета, плашка профиля и отдельная кнопка обновления убраны.
- Дев-панель: + НАВЫКИ (UP), КЛАН, ТОРГОВЕЦ, РЕСПАУН, ОБНОВЛЕНИЕ НУЖНО/НЕТ,
  HUD: ДАННЫЕ (нагруженное состояние), ТАЧ (раскладка Touch.uss); DEV ▾
  сворачивает панель.

- `python3 -I tools/parity.py ../kern-ui-lab/index.html index.html` —
  каждый `id`, ключ i18n, обработчик, окно и экран оригинала: сохранён или

  обновления) и снятого показателя «РЕАКТОР/EN», которого нет в игре.

- `tools/snap.sh` — снимки любого экрана/окна (эталон `orig-*` и `v2-*` в
  `tools/shots/`).
