# Выводы, ответ которых уже доставлен

Эти скрипты **не часть конвейера**. Каждый отвечал на вопрос «сколько ступеней
и почему именно столько», ответ давно лежит в `css/` и в USS игры, и повторный
запуск ничего не проверяет.

Они сохранены не как шаг, а как **обоснование**. Число в токене без причины —
это то же самое волшебное число, ради борьбы с которым шкалы и заводились;
здесь лежит причина.

| файл | какое число обосновывает |
|---|---|
| `derive-alpha-scale.py` | ступени шкалы прозрачности: вывод из фактического распределения альф по логит-оси, взвешенного частотой |
| `derive-translucency.py` | семантические токены полупрозрачности и карта замены — вместо того, чтобы компоненты дописывали альфу руками сотнями мест |
| `derive-utilities.py` | какие утилиты покрывают инлайн-наборы: жадное покрытие множеств |
| `extract-inline.py` | почему инлайн переехал в правила экранов, а не в утилиты: 98 применений дали 92 разных набора, повторяется почти ничего |

Запускать имеет смысл только тогда, когда меняется сама постановка: другой
макет, другое распределение значений, другой вопрос. Тогда это уже новый вывод,
и его результат снова уедет в CSS, а скрипт — обратно сюда.
