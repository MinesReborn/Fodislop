# Инвентаризация интерфейса Kern ↔ Unity Legacy OpenMines

Стадия: макет на согласование. В Unity ничего не переносится. Предыдущие
`visual/kern-ui-lab/proposal/` и `.superdesign/` не используются как референс.

## Как собраны факты

- **Legacy**: `../OpenMines/client/Assets/Scenes/m1client.unity` разобран
  `tools/legacy_scene_rects.py` в дерево RectTransform (якоря, размеры,
  компоненты, тексты, шрифты, цвета). Цепочки якорей ключевых узлов лежат в
  `data/legacy-rects.json`; макет накладывает их поверх себя (`?overlay=1`),
  решая раскладку UGUI независимо от своего CSS. CanvasScaler:
  ScaleWithScreenSize, эталон 1163.6×654.5, match = 1 (по высоте).
  Значения — из `GUIManager.cs`, `ChatManager.cs`, `ChatLineInfo.cs`,
  `MiniSkill*.cs`, `SkillButton.cs`, `PopupManager.cs`.
- **Сервер**: действующий — Rust `OpenMines/crates/server/openmines-server`
  (окно навыков `game/logic/up_building/mod.rs`, каналы `game/mod.rs`).
  C#-референс `docs/reference/server_reference` — только для сверки.
- **Kern**: `Assets/Resources/UI/**/*.uxml`, `Styles/*.uss`, `Scripts/UI/**`,
  протокол `Packages/MinesServerNetworking`. Снимков Unity-рендера Kern в этом
  проходе нет: Kern-сторона сверена по разметке и коду, не по кадру.

Формат строки: **элемент** — место · текст/формат · источник значения ·
условие показа · действие. «→» — решение для макета.

## 1. Bootstrap

- **Экран загрузки** — `BootstrapLoadingScreen.uxml`: заголовок
  `assetload.title` «Загрузка мира», строка фазы `BootstrapLoadingPhase`
  (например `bootstrap.loading.shaders` «Компиляция графических конвейеров...»).
  → Оставить два текста; ничего не добавлять. В Legacy своего меню нет:
  клиент сразу грузит мир (`BlackPadImage` + логотип + `loader.png`,
  `StartupButtons`: `ConnectionText`, `RECONNECT`, `ИГРАТЬ`).

## 2. MainMenu (Kern; в Legacy аналога нет)

Привязано к данным/коду (`MenuNavigationPresenter`, `MenuModalManager`,
`MainMenu`):

- **Кнопка спуска** `PlayButton` «НАЧАТЬ СПУСК В ШАХТУ» → запуск перехода
  в MainGame с экраном фаз загрузки (`LoaderPhaseLabel`, `N / 5`, фазы
  `menu.loading.phase.*`, кнопка `menu.cancel_descent`).
- **Выбор сервера** `ServerSelectButton` → окно с двумя реальными вариантами:
  сервер по `ConnectionTransportConfig.DefaultServerHost:Port`
  (`127.0.0.1:8090`) и офлайн-песочница (`UseDummyConnection`).
- **Версия** `FooterVersionButton` — `mainmenu.version` «ВЕРСИЯ {0}» /
  `_dev` / `_editor`.
- **Боковые кнопки**: настройки, Discord, Telegram, VK, выход — действия есть.
- **Обязательное обновление** — данные `OutdatedClientPacket(NewVersionCode,
  Name, Description, UpdateURL, CLIArgs)`; сейчас `StatusProcessor` рвёт
  соединение и открывает `UpdateURL`. Строка `network.error.outdated`:
  «Версия: {0}\n{1}\nСкачать: {2}».
  → По заданию: пока обновление не выполнено, **на месте кнопки спуска**
  стоит кнопка обновления («ОБНОВИТЬ» + имя версии из пакета); отдельной
  кнопки/баннера обновления нет.

Статичный текст без данных (выдумано, в макет **не** берётся как данные):

- `mainmenu.online_count` «4 В СЕТИ» — константа; реальный онлайн
  (`OnlinePacket`) приходит только после подключения к миру. → убрать из меню.
- Карточки серверов «СЕВЕРНАЯ ЕВРОПА [HADES-ALPHA]», «142 ШАХТЁРА», «38 МС»,
  глубина, сид, «Опасность: Высокая» — константы в UXML/`MenuModalManager`.
  → убрать; показывать адрес и режим.
- Хроника, тикер новостей, changelog «v0.9.0», журнал «Проверка файлов … OK»,
  маршрут ОРБИТА/СПУСК/ПОВЕРХНОСТЬ, подсказки ENTER/ESC — константы.
  → не показывать как содержимое; хроника/ремонт без источника данных убраны.
- Профиль «ШАХТЁР-774 [DVM]», «РАНГ 4 · БУР TIER-2», досье, токен — константы.
  → убрано по заданию (вместе с планетой и схемой шахты).
- Заголовок «Мир ждёт / под поверхностью.», подзаголовок, `brand_sub` —
  оформительский текст Kern, не данные. → оставлен как есть.

## 3. Авторизация (Kern `Gateway.uxml`)

Цель: отдельный полноэкранный экран внутри потока MainMenu (не сцена).

- Протокол **не знает** логина, пароля и регистрации: `ClientHelloPacket`
  несёт токен устройства, сервер отвечает `AuthTokenPacket`
  (`gateway.auth.login_hint`, `register_hint`, `recover_hint`).
- Рабочие действия: **«ВОЙТИ В МИР KERN»** (`gateway.auth.submit`, вход по
  токену), **«ВОЙТИ ЧЕРЕЗ VK»** (device-flow, состояния `gateway.auth.vk_*`),
  **«Офлайн режим (Dummy)»**. Строка подсказки `AuthHint`.
- Поля логина/пароля, вкладка регистрации, EULA, «Забыли пароль?»,
  «Запомнить», «Авто-вход», чипы «[GPU] OK / [FMOD] SYNCED / [WORLD] MOUNTED» —
  заглушки без протокола. → не показывать как работающие поля.

## 4. Онбординг (Kern `Gateway.uxml` → в поток MainMenu)

Три шага, все поля привязаны к настройкам (`GatewayOnboarding`):

1. «Доступность»: Масштаб интерфейса `OnbUIScale` (100/115/130/150/175 %).
2. «Графика»: Качество освещения `OnbGraphicsPreset` (Быстрое/Среднее/
   Высокое/Ультра), Ограничение частоты кадров `OnbFrameRate`,
   Вертикальная синхронизация `OnbVSync`.
3. «Управление»: Схема движения `OnbControlScheme` (WASD / Стрелки;
   Указатель мыши), Громкость `OnbMasterVolume` 0–100 %, Приглушать в фоне.

Кнопки: «← НАЗАД», «ПРОПУСТИТЬ», «ДАЛЕЕ →» / «НАЧАТЬ ЭКСПЕДИЦИЮ →».
→ Состав сохраняется; подписи-«хинты» про FMOD/Master Bus/UI Toolkit/«каскадный
расчёт» — технический жаргон; в макете оставлены названия полей, хинты
укорочены только там, где они описывают действие (решение за пользователем).

## 6. Тач-варианты (Legacy аналога нет; источник — Kern `Styles/Touch.uss`)

- Только альбом. 1 CSS px = 1 dp; устройства и безопасные зоны —
  `Tests/Shared/MobileDeviceMatrix.cs`. Форма: Phone при короткой стороне
  < 600 dp, иначе Tablet (`ScreenShapeRules`); Micro/Short в макет не входили.
- Места: панель игрока сверху слева у `--touch-edge` 6; миникарта сверху
  справа 104 / 136 (планшет); системный ряд (Движение, КАРТА МИРА, чат,
  локальный чат «…», меню ☰) и ряд респаун/здания/помощь — левее миникарты;
  стик 120 / 148 снизу слева; док справа снизу: C G Z W, «Геология»,
  «Лечение», «Копать» (64); хотбар внизу правее стика; цели 44 dp.
- Вид блоков — Legacy при 1 эт. ед. = 1 dp (планшет 1.15): уровень и кредиты
  на таче **оставлены** (Touch.uss их прячет — это потеря данных).
- Отступления от Touch.uss: автокопание и программатор — в нижнем поясе над
  мини-навыками (иначе на SE касаются стика); онлайн и строка версии/FPS —
  под миникартой; мини-чат — сверху по центру.
- «Бонусы» на таче — первая кнопка верхнего ряда (панель игрока со строкой
  геологии иначе выталкивает её под системный ряд на SE); миссия — сверху по
  центру под рядами, мини-чат тогда ниже неё; подсказка предмета — под
  роботом.
- Чат на таче: колонка Legacy поверх левой части (ширина min(300 dp, 42 %)),
  стик сдвигается за неё, хотбар и мини-навыки на время чата скрыты.
- Окно навыков на таче: две колонки (робот 397×260 dp слева, описание и
  «Улучшить» справа), «ВЫЙТИ» в строке заголовка.
- Меню на таче — правила Touch.uss (шапка 52, колонка 52 %, кнопки 44, вход
  в две колонки 34 % / 66 %, онбординг 96 %); на телефоне подзаголовок и шаги
  онбординга скрыты (как в Touch.uss), в состоянии обновления скрыт
  декоративный заголовок, чтобы кнопка и описание обновления поместились.

## 7. Отступления от Legacy на десктопе

- Строка «ОНЛАЙН N (N)» и строка версии/FPS подняты в полосу 2–14 эт. ед.:
  при открытом чате на 4:3 сдвинутая панель игрока и «Бонусы» иначе
  наезжают на них (в Legacy с теми же якорями — то же наложение).
- Подсказка предмета опущена с y 69 на 118 эт. ед.: в Legacy её центр
  перекрывает панель миссии, когда обе видны (состояние `busy`).
- Панель игрока и панель груза растут по тексту (ContentSizeFitter Legacy):
  строка геологии и «Груз 128%» не обрезаются; у груза справа место под бокс.
- Иконки кнопок — спрайты Legacy/Kern одной заливкой (`mask`), не цветные.
- Шрифты Kern: Exo 2 и JetBrains Mono; Unbounded не используется.

## 8. Расхождения, требующие решения пользователя

1. Чат: Legacy-колонка слева со сдвигом HUD или текущая полоса Kern справа
   от миникарты. Макет: Legacy (по заданию «каналы сохранить, как в клиенте»).
2. Корзина: Legacy «число» или Kern «число/вместимость + полоса».
   Макет: Legacy.
3. Ряд кнопок справа: Legacy добавляет звук, музыку, настройки, полный
   экран, консоль. Макет: Legacy состав.
4. Заголовок окна навыков: сервер шлёт мусор — чинить на сервере.
5. Хинты онбординга с жаргоном — оставить или переписать.
6. Планшет: Touch.uss держит HUD в тех же dp, что и телефон, — на iPad Pro 13
   блоки мелкие при огромном пустом поле. Макет: 1.15; можно поднять.
